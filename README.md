# Student Result Dashboard

A beginner-friendly frontend project that displays student information, course scores, and academic performance using HTML, CSS, and JavaScript.

## Overview

The Student Result Dashboard demonstrates how JavaScript can organize student information, calculate academic results, and display data dynamically on a webpage.
The project was built as part of my frontend development learning journey to practise JavaScript fundamentals and DOM manipulation.

## Features

* Display student information.
* Display course names and scores.
* Determine whether a student passes or fails a course.
* Calculate the total number of courses.
* Calculate the average course score.
* Display the student's overall result.
* Dynamically generate course elements using JavaScript.
Additional interactive features, such as adding course results through a form, can be developed as the project progresses.

## Technologies Used

* **HTML5:** Structures the webpage.
* **CSS3:** Styles the dashboard and course cards.
* **JavaScript:** Handles student data, result calculations, conditions, loops, functions, arrays, objects, and DOM manipulation.

## How It Works

### 1. Student Information
JavaScript stores student details in an object.

### 2. Course Information
An array of objects stores the course names and scores.

### 3. Result Calculation
A function checks whether a score meets the passing mark.

### 4. Average Calculation
A loop adds the course scores, and the program calculates the average.

### 5. Dynamic Display
JavaScript uses DOM methods to display student information and generate course elements on the webpage.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
You can also open the folder in Visual Studio Code and use a local development server or the Live Server extension.
